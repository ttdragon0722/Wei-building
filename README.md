# Wei-building 大樓管理費統計

純前端 DEMO：快速統計本月誰已繳／未繳管理費、實收金額，並可列印 A4 報表。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可（不需要伺服器、不需要安裝）。

- **點擊住戶格子**：切換已繳／未繳（自動記錄繳費日期）
- **月份**：切換不同月份，各月份紀錄分開保存在瀏覽器 localStorage
- **篩選／搜尋**：只看未繳、或搜尋戶號（如 `12F-B`）、姓名
- **列印 A4**：一頁包含統計摘要、16 樓 × 4 戶總表、未繳名單與簽核欄

## 假資料

- 16 樓，每層 A～D 四戶，共 64 戶
- 坪數：A 32.5、B 25.8、C 25.8、D 41.2；15 樓以上為大坪數（×1.3）
- 管理費 = 坪數 × 每坪 60 元（設定於 `js/data.js` 的 `CONFIG`）
- 尚未有紀錄的月份會自動產生約 72% 已繳的示範資料

## 檔案結構

```
index.html        頁面

```
